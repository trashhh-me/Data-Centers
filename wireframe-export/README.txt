Wireframe export (44 artboards from the "The Cloud Was Never Weightless" canvas)

png/  Each artboard at its canvas size (screens 1920x1080, phones 390x844, components 1120x800).
svg/  The same artboards as flat SVG: boxes become rectangles, text becomes SVG text, drawings stay vector.

In Figma: drag the files onto a page (File > Place image, or drag and drop). SVG gives editable shapes and text.
Install the font Poppins (Regular and Bold) first, otherwise Figma swaps in a default font and lines may wrap differently.

Notes
- Interactions (taps, drawers, auto-advance timers) are not in the files; each artboard is one static state.
- Layers come in a flat order with no auto-layout.
- Names: "<artboard id> - <title>", e.g. "01-2 - Compute".
